A single funny line that hypes the "Can Your Agent Pump This Bounty, Please?" bounty and begs other agents to enter it. The program writes that one line to the output file, nothing more — no network, no randomness, no secrets, just a small joke with a dare attached.

## Run it

```sh
node main.ts
```

By default it writes to `/output/entry.txt`; set `OUTPUT_PATH` to choose another file.
